# QA: 独立確率（連対率・連複率）への振り切り（#719 / エピック #723・2026-09-27）

「結局予想が改善したのかよく分からない。確率を出すことに振り切った方がいいのでは」という問いかけに対し、
実測状況（#703 のベースライン・ADR 0052/0053/0076）と文献調査（`docs-original/719-literature-probability.md`）を
提示したうえでの方針確認の記録。
蒸留先: `docs/specifications/learned-model-harness.md`（決定ログ #719）・`backtest.md`（評価プロトコル）・
`probability-estimation.md`（独立確率の評価）。

## Q1: 確率は市場を土台にするか、市場とは独立に出すか

- 背景: #703 の実測で、本番のブレンド（α=0.2）は市場単体より当てはまりが悪く（eval ΔR² −0.0045）、
  純モデルの最適重みはほぼ 0 だった。「市場そのもの（α=0）を土台にする」案を最初に提示した。
- 回答（ユーザー）: **市場とは独立に出す**。「市場を重視しすぎるとプラスにならないなら、そもそも確率機は
  いらない」「確率を出したうえで市場のズレを見る。まず確率を別に出すことが大事」。
- 帰結: 市場を土台にする案は撤回。独立確率を一級目標にし、市場とのズレは後段（#722）で見る。

## Q2: どの券種を主に考えるか

- 回答: **馬連 > ワイド > 3連複 > 単勝**。単勝では基本買わない。
- 補足: 「結局は連対率・連複率の確率。勝つ確率は内部的に出して、検査を重ねて精度を上げていく」。
- 帰結: 内部は各馬の強さ（勝つ確率）、出力と評価は連対率・馬連（1-2 着ペア）を主指標にする。

## Q3: 着順と馬ごとの適性を学習に入れるか

- 回答: 着順は 1 着だけでなく学習に入れる（連複を取りたいので）。長距離・ダートの得意不得意のような
  馬ごとの適性も学習させる。
- 帰結: #720 で Plackett-Luce の上位 k 着尤度、条件別適性（縮約付き）を実装する。

## Q4: 過去の棄却記録の扱い

- 回答: **参照はするが一旦無視**（判断は縛られない）。
- 帰結: ADR 0052/0053/0063 などは衝突点として列挙し、再実施の理由を決定ログに明記して supersede する。

## Q5: 方針を文献で確かめるか

- 回答: このやり方でいいのか、論文等の検索を並行して行う。
- 帰結: 設計（強さ → Plackett-Luce → 組合せ確率）は文献の本流。一方、ズレを直接買いシグナルにすると
  Benter Table 3/4 の罠にはまるため、判定は市場と合成したときのモデル重み α>0（#722）で行う。
