# QA: 確率ロジック刷新の方向性（#703・2026-09-21）

「予想ロジック改善」の依頼に対し、文献サーベイ（`docs-original/703-probability-logic-literature-survey.md`）
とリポジトリ調査（open issue・Tentative 要件・棄却 ADR の範囲確認）を提示した上での方向性質問票。

## Q1: どの改善方向から着手するか

- 背景: 「予想ロジック改善」はスコープが広く、resolution 天井（ADR 0058/0059）等の棄却済み路線が
  多い領域のため、着手前に方向を確定する必要があった。
- 選択肢:
  1. **確率ロジック本体の刷新**（計測器 → 対数プール → Harville λ。文献の裏付けが最も強く新データ不要）〔推奨〕
  2. 既存 open issue の校正（#218 live α 再校正 / #625 番兵除去後の ROI ゲート再測定）
  3. EV 定義の統一（blended への一本化）
  4. 執行側の実証（predictions 記録復活 + REQ-D01-006）
- **回答: 1. 確率ロジック本体の刷新**（単一選択）。
- 補足指示: 「モデルは賢いのでネット上の論文等の精査も考えてほしい」「着順等のデータはローカルに
  あるのでそれも利用してほしい」→ 文献サーベイを実施し、検証はローカル DB（結果付き 5,052R）の
  バックテストで行う方針とした。

## 帰結

- 3 フェーズ（計測器 → Harville λ → 対数プール）・各フェーズ独立 PR のプランを承認済み。
- 非選択の方向（EV 定義統一・ズレ増額の符号検証・券種間相対ミスプライシング・支持率足切り・
  exploded logit)は follow-up issue として起票する（実装しない）。
