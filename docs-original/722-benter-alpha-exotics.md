# #722 独立確率 × 連系市場の Benter 型合成の実測ログ（2026-09-30）

独立確率（#720 の割引 PL top-k。市場を混ぜない）が、連系市場（馬連・ワイド・3連複）の確定オッズの持たない情報を
持つかを、Benter (1994) の条件付きロジット合成で判定した実測ログ（一次資料）。
方針の確認は `qa/QA-benter-alpha-722.md`。蒸留先: `knowledge/learned-model-harness.md`（決定ログ #722）・
`knowledge/product-goals.md`（ADR 0063 の再検証）・`knowledge/probability-estimation.md`・`knowledge/netkeiba-datasource.md`。

## 構成

- 評価器: `scripts/predict-check/benter_alpha.py`（テスト `test_benter_alpha.py`）。
- モデル（券種ごと・1 レースの全組合せで正規化）: `p_c ∝ exp(α·ln f_c + β·ln π_c)`。
  - f: 独立確率の p_win とレースごとの λ（`lam2`・`lam3`）から、`prob_ledger.combo_probs`（割引 Harville）で作る。
  - π: 確定オッズから `(1/O_c) / Σ(1/O)`（レース内の正規化で控除は消える）。ワイドは帯の中点。
    3連複の無投票の組は、売れた組の最小 π の半分を置いて正規化し直す（QA Q2）。
  - 尤度: 馬連・3連複は的中 1 組のカテゴリカル、ワイドは的中 3 組の複合尤度（QA Q3）。
  - 市場単独 = (α, β) = (0, 1)。擬似 R² は一様予測比（`1 − ΣNLL / ΣNLL_一様`。NLL_一様 = 的中数 × ln 組合せ数）。
- 推定: Newton 法（凹の対数尤度）。CI はレース単位ブートストラップ 1000 回（seed 42）。
  馬連・3連複は Hessian SE も並べる（ワイドは複合尤度なので出さない）。
- 判定（事前に固定・QA Q5）: fit 窓の α の CI > 0、eval 窓の α の CI > 0、eval 窓の ΔR²（合成 − 市場）の CI > 0、
  NLL 差の CI < 0 をすべて満たしたら「エッジあり」。ROI は参考値のみ。
- 窓: fit = 2025-07-01〜12-31（dev 窓）、eval = 2026-01-01〜08-31（test 窓・1 回だけ）。オッズは確定値だけを使う。

### test 窓の前の独立検証（評価器）

test 窓を測る前に、評価器を独立したエージェントに敵対的に検証させた（結論: Go）。

- 別実装（評価器と prob_ledger を使わず、素朴なループの割引 Harville ＋ scipy の Nelder-Mead）で、3 券種とも
  θ̂ と 3 通りの擬似 R² が一致した。勾配・Hessian は数値微分と有効数字 6 桁で一致（ワイドの的中 3 組を含む）。
  的中組をランダムにすると R² が負に崩れた。馬番の並びの取り違え・的中組の取り違えは否定できる。
  （ここまでは独立検証エージェントの単発の確認で、スクリプトは残していない。）
- f 単独の R² 0.1586 は、#720 の独立確率（ledger v2 / v2.1 dev の馬連 0.15856）と近い。母集団（prob_ledger の 1,705R と
  この評価器の 1,705R）と数え方が同じ系統なので、馬番の並びが崩れていれば大きく下がるはずの値が保たれている、という確認。
- 下の「dev 窓の参考値（再現手順つき）」で、β=1 固定の α̂・再校正による ΔR² の内訳・並べ替えプラセボを出し直した。
- 指摘を受けて test の前に直したこと（判定・α・β の推定値は変わらない）:
  - ワイドの参考 ROI の閾値: 組の的中確率を 3p で数える（以前は p で、期待値 > 3 を要求していた）。
  - 参考列の追加: 市場だけを再校正したモデル（α=0・β だけ推定）に対する ΔR²。dev 窓の ΔR²（合成 − 市場）の 63〜74% は
    β の再校正で説明できる（下の参考値）ので、独立確率の寄与の目安として並べる。
  - 記録先の検査: `--ledger` は docs-original/ にある既存の .md に限る（捨てファイルで test 窓を覗かない）。
  - 除外理由の名前を実態に合わせた（`market_horse_not_in_starters`）。
- 読むときの注意:
  - 判定の条件 3（ΔR² の CI > 0）と条件 4（NLL 差の CI < 0）は、同じ再標本・正の分母なので実質同じ条件。
  - この評価器のワイドの擬似 R²（的中 3 組の NLL の和 ÷ 3·ln 組合せ数）は、prob_ledger のワイドの R²
    （3 組の平均 ÷ ln(組合せ数 / 3)）と定義が違うので、数値を横に並べて比べない。
  - eval 窓の ΔR²・NLL 差・再校正市場との差の CI は、fit 窓の (α̂, β̂)・β（再校正）を固定したまま eval のレースだけを
    再標本した条件付き CI で、推定値の誤差を含まない（やや狭く出る）。判定は α の条件で決まるので、結論には効かない。

### dev 窓の参考値（再現手順つき）

評価器の出力に無い参考値を、次のスクリプトで出した（`scripts/predict-check` で `PYTHONPATH=.`、numpy・scipy 入りの venv）。
判定には使わない。

| 券種 | β=1 固定の α̂ | 再校正の β（α=0） | 擬似 R²（市場 / 再校正 / 合成） | ΔR² のうち再校正の割合 | 並べ替えプラセボの α̂（5 回） | 出典 |
|---|---|---|---|---|---|---|
| 馬連 | +0.0219 | 1.0794 | 0.2641 / 0.2651 / 0.2657 | 63% | −0.004〜+0.010 | 本ファイル#dev 窓の参考値（再現手順つき） |
| ワイド | +0.0424 | 1.0974 | 0.1956 / 0.1968 / 0.1972 | 74% | −0.014〜+0.013 | 本ファイル#dev 窓の参考値（再現手順つき） |
| 3連複 | +0.0369 | 1.1055 | 0.2591 / 0.2608 / 0.2616 | 68% | −0.016〜+0.037 | 本ファイル#dev 窓の参考値（再現手順つき） |

- β を 1 に固定すると α̂ は正になる。負の α̂ は、β̂ > 1（市場を尖らせる）と同時に推定したときの偏回帰で、
  市場を再校正した後に独立確率が加える情報はむしろ逆向き、という読み。
- f をレース内で並べ替えると α̂ はほぼ 0 に戻る（実データの −0.10〜−0.13 に比べて小さい）。

```python
import os
import numpy as np
from scipy.optimize import minimize_scalar
import benter_alpha as ba
import prob_ledger as pl

D = os.path.expanduser("~/paddock-backups/pinned/")
probs = pl.load_probs(D + "722-benter-alpha/k3.tsv")
date, horses, fins = ba.load_results(D + "722-benter-alpha/pl_raw.tsv")
po, pay, _ = ba.load_odds(D + "721-final-odds/final_odds.tsv", False)
rng = np.random.default_rng(42)
for bt in ba.BET_TYPES:
    races, _ = ba.collect(bt, "2025-07-01", "2025-12-31", date, horses, fins, probs, po, pay, True)
    pk = ba.pack(races)
    un = ba.uniform_nll(pk)
    a1 = minimize_scalar(lambda a: ba.race_nll(pk, np.array([a, 1.0])).sum(), bounds=(-1, 1), method="bounded").x
    theta, _, _ = ba.fit(pk)
    beta, _ = ba.fit_beta(pk)
    r2 = {k: ba.pseudo_r2(ba.race_nll(pk, np.array(t)), un)
          for k, t in (("market", [0.0, 1.0]), ("recal", [0.0, beta]), ("blend", theta))}
    share = (r2["recal"] - r2["market"]) / (r2["blend"] - r2["market"])
    placebo = [ba.fit(ba.pack([ba.Race(combos=r.combos, log_f=rng.permutation(r.log_f), log_pi=r.log_pi,
                                      winners=r.winners) for r in races]))[0][0] for _ in range(5)]
    print(bt, a1, beta, r2, share, min(placebo), max(placebo))
```

## 結論（test 窓の測定後）

- 判定は 3 券種とも「エッジなし」。事前に固定した 4 条件（条件 3・4 は実質同じなので、独立な条件は 3 つ）のうち、
  α の 2 条件（fit 窓・eval 窓の α の CI > 0）を 3 券種とも満たさない。
- eval 窓でも α は負か 0（馬連 −0.080・ワイド −0.030・3連複 −0.069）。fit 窓の「有意に負」はおおむね再現した（ワイドは CI が 0 を跨ぐ）。
- ワイド・3連複の ΔR²（合成 − 市場）は正で CI も 0 より上だが、市場だけを再校正したモデルに対しては 3 券種とも CI が 0 を跨ぐ。
  上乗せは β の再校正（本命側を少し厚くする）の効果で、独立確率の寄与ではない。
- 参考 ROI は CI が広い（3連複 1.040 [0.489, 1.773]・馬連 0.276・ワイド 0.262）。事前の取り決めどおり判定には使わない。
- ADR 0063 の再検証条件のうち、データ量（リーク無しのエキゾオッズと結果が数百 R）は満たした（fit 1,698〜1,705R・eval 2,132〜2,139R・
  確定オッズのみ）。ただし ADR 0063 の仮説そのもの（ブレンド確率をエキゾに広げたときの実オッズとのズレ・馬単を含む）は
  この評価器では測っていない。それは #707（券種間のミスプライシング）の範囲。
