# #720 市場非依存の割引 PL top-k の実測ログ（2026-09-29）

独立確率モデル（割引 Plackett-Luce・上位 k 着の尤度・`results` のみの特徴量）を作り、#719 の評価器
（`prob_ledger.py`）で dev → test の順に測ったときの実測ログ（一次資料）。
蒸留先: `knowledge/learned-model-harness.md`（決定ログ #720）・`knowledge/probability-estimation.md`（独立確率の評価）・
`knowledge/ci-pipeline.md`（harness テストの CI）。数値の正本は `docs-original/719-prob-ledger.md` の v2 dev / v2 test 節。

## 事前に固定した採否基準（計画承認時）

- dev（2025-07〜12）で、pure（現行純モデル → 素の Harville）に対する **Δ馬連 NLL と Δ連対 log-loss が両方 ✅**
  （対応ありブートストラップの 95% CI が改善側で 0 を跨がない）なら、test（2026-01〜08）を **1 回だけ**測る。
- test でも両方 ✅ なら採用。比較は同じ実行で並べた pure との対応ありの差で行う。
- PL は「学習した λ」と「λ=1」の 2 系統を並べる。

## 構成

- 特徴量: `scripts/harness/pl_features.py`（26 列）。元データは `pl_features_extract.sql`（`results` ＋ `races` の
  許可列のみ。odds・popularity を選ばない）。馬のキーは馬名。
  - 履歴・フォーム: 出走数（log1p）・履歴なし・前走からの日数・直近 3 走の相対着順・前走の相対着順・中止率。
  - タイム: 直近 3 走の勝ち馬とのタイム差（秒/1000m）・速度 z の最大と平均（コース × 馬場の基準タイムは月初より前の
    完走 30 件以上から。±4 でクリップ）・速度なしフラグ。
  - 適性（全体の相対着順へ擬似 2 件で縮約した条件別成績との差）: 芝ダ・距離（±200m）・場・馬場（良 / 道悪）。
    芝ダの出走割合、今回の距離と過去平均距離の差（符号あり・絶対値）。
  - 当日: 斤量・馬体重・増減・枠の相対位置。騎手・調教師: 勝率・3 着内率（擬似 30 件で縮約）。騎乗数（騎手のみ）。
- as-of: 履歴・騎手・調教師は当日より前（同日の別レースも除く）、基準タイムは月初より前。
- モデル: `scripts/harness/train_pl_topk.py`。段 s で exp(λ_s·u) の softmax（λ1=1、3 着段以降は λ3 共有）。
  L2=1.0（β のみ・レース数で正規化しない総和の尤度に足すので、学習窓が長いほど実効的に弱まる）。L-BFGS-B（λ ∈ [0.05, 5]）。
  学習レースが 50 未満の月は予測を出さない（今回の窓では該当なし）。縮約の擬似件数（APT_M=2・JOCKEY_M=30）と L2 は固定で、dev では振っていない
  （dev の反復は k と λ だけ。QA Q7）。
- walk-forward: 学習開始 2025-03-01、予測月ごとに月初の前日までで標準化と学習をやり直す。

## 結果（ledger v2 dev / v2 test）

| 窓 | 系統 | 馬連 NLL | 馬連 R² | 連対 log-loss | 連対 R² | ワイド R² | 3連複 R² | 単勝 R² |
|---|---|---|---|---|---|---|---|---|
| dev（1,716R） | pure | 4.1249 | 0.053 | 0.3965 | 0.045 | 0.055 | 0.053 | 0.046 |
| dev | pl_k3 | 3.6641 | 0.159 | 0.3585 | 0.136 | 0.161 | 0.155 | 0.146 |
| test（1,722R） | pure | 4.2066 | 0.057 | 0.3859 | 0.049 | 0.062 | 0.059 | 0.054 |
| test | pl_k3 | 3.6617 | 0.179 | 0.3434 | 0.153 | 0.194 | 0.186 | 0.161 |
| test | pl_k3_l1 | 3.6650 | 0.179 | 0.3436 | 0.153 | 0.195 | 0.187 | 0.159 |

- test の Δ（pl_k3 − pure）: 馬連 NLL −0.545 [−0.594, −0.501] ✅、連対 −0.0424 [−0.0462, −0.0390] ✅。副指標もすべて ✅。
  **事前基準を満たしたので採用**（λ=1 版も同様に ✅）。
- 較正（CORP・連対の帯外点 / 10）: pure 9 → pl_k3 5（dev は 8 → 0）。MCB 0.00227 → 0.00073。test では較正のずれが残る。
- 忠実性サニティ（pure win Brier）: test 0.064316 で v1 と一致。
- 比較対象の性質: pure（`model_win_pure`）は `recent_form`・`jockey_recent_form`（人気との差）を含み、厳密には市場非依存ではない
  （#720 の計画修正コメント C1 で ledger への注記を約束した事項。ledger の末尾に計測なしの注記節として追記した）。
- 市場参考列（単勝オッズ → 素の Harville・点推定）: test の馬連 NLL 3.278（一様比の R² 約 0.265）、連対 0.313。
  独立確率はまだ市場の単勝より当たらない（馬連 R² で約 0.09 差）。市場と合わせて情報が増えるかは #722 で測る。

## 観察

- 改善の大部分は、現行純モデル（手作り線形スコア）から学習ランカーへの置き換えによる。単勝 R² も 0.054 → 0.161 に上がった。
- ADR 0053（2026-06）の学習ランカーは「α=0.2 blend を超えるか」で棄却されたので、純モデル比の改善幅は同じ物差しでは測られていない。
  今回の物差し（独立精度）での改善は大きいが、市場を超えたわけではない。
- 学習 λ と λ=1 の差は test ではほぼ無い（馬連で点推定 −0.003）。割引の効きは小さい。
