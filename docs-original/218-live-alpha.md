## 4. 結論（事前コミットの適用）

- 朝 = 判定不能 → 事前コミット「採用候補のときだけ α=0.2 を残す」に従い **α=0 に倒す**。
- 朝の市場は緩い（ゆえにモデルが足せる）という #284 の保留理由は、この 382R では支持されなかった。どの時点でも α=0.2 は
  市場を有意に上回らず、点推定は的中・包含でわずかに劣る向き（単勝・top5 包含の CI 上限は 0.0 ちょうど。`judge` は境界を
  悪化に含めないので判定不能。境界を含める流儀なら「悪化」だが、どちらでも決定は α=0 で変わらない）。
- 17 開催日の小さな母集団で CI は広い。「α=0.2 が朝に有害」とまでは言えないが、「有益」の証拠も無い。
