# #719 独立確率の ledger（版ごとの実測ログ）

市場非依存の確率系統を、同じ物差しで版ごとに比べる実測ログ（一次資料・append-only）。
各節は `scripts/predict-check/prob_ledger.py --ledger ... --label ...` が追記する。手で書き換えない。

読み方:

- **主指標**: 馬連 NLL（`quinella_nll` = −ln P(実際の 1-2 着ペア)）と連対 log-loss（`top2_nll`）。いずれも**小さいほど良い**。
- `*_r2` は一様予測比の擬似 R²（大きいほど良い）。
- 各値の `[ ]` はレース単位ブートストラップの 95% CI。
- Δ 列は baseline（`pure` = `model_win_pure` → 素の Harville）との差。✅ は CI が改善側で 0 を跨がない、❌ は悪化側で跨がない。
- **採否は test 窓だけで判断する**。dev 窓は反復用（`knowledge/backtest.md`「評価プロトコル」）。
- 市場参考列は別母集合で、ゲートにしない。
- 追記は main 最新の上で行う（並行ブランチで末尾に追記すると、マージ時に末尾で競合する）。

定義・経緯は `knowledge/learned-model-harness.md` の決定ログ「#719」。
