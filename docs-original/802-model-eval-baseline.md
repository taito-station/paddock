## 4. 読み取り（この時点の所見）

- ◎ の的中率と top5 包含は、本番構成（blended）と市場の差が CI 内で、区別がつかない。`product-goals.md`「エッジの所在」の
  「現行精度は事実上ほぼ市場由来」と同じ。
- **win LogLoss は blended が市場より有意に悪い**（Δ +0.0011・CI が 0 を跨がない）。的中率では見えない差が、連続指標では出る。
  α=0.2 のブレンドが純モデルの悪い較正（pure は 0.2 以上の帯がほぼ空＝確率を潰している）を 2 割持ち込んでいる形。
  #703 の「α=0.2 有害の機序」と向きが一致する。本 issue では採否の対象にしない（土俵を作るのが範囲）。
- 純モデル単独は全指標で市場に大きく劣る（◎ 単勝 21.0% vs 32.5%）。
- 参考（dump 全期間 2025-01〜2026-08・5,491R から同着 7 を除いた 5,484R・bootstrap 200）: ◎ 単勝 market 32.9% / pure 19.8% / blended 32.7%。
