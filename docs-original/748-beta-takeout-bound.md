# #748 連系市場の較正の偏り（β>1）は控除を越えるか — fit 窓だけでの見積もり（2026-10-04）

#722 で、連系市場の確定オッズに条件付きロジット `p ∝ π^β` を当てると β>1（本命側の組が薄く売られている向き）だった。
#748 は「この偏りを使って本命側の組を買うと、控除を越えて取れるか」を、買う時点のオッズで選んで払戻で精算して測る計画だった。
計画の敵対的レビューで、選び方の規則が**ほとんど発火しない**ことを fit 窓だけで確かめられると指摘され、測る前に結論が出た。
方針の確認は `qa/QA-beta-takeout-748.md`、蒸留先は `knowledge/learned-model-harness.md`（決定ログ #748）と
`knowledge/product-goals.md`（非目標 B）。**eval 窓（2026-01〜08）のオッズと結果は一度も読んでいない**（数えたのは、計画時の事前調査と計画レビューでの、
発走 40 分前の窓に入ったスナップショットがあるレースの件数だけ）。

## 1. 計画で事前に固定した規則（qa Q1〜Q4）

- 買う時点: 発走 40 分前の窓に入った最初のスナップショット
- β: 評価プロトコルの fit 窓（2025-01-01〜12-31）の確定オッズで、券種ごとに α=0 の再校正 β を推定して固定
- 選び方: 再校正 EV = p × オッズ ≥ 1.0 の組を全部、各 100 円（p = π^β / Σπ^β、π はレース内で正規化した 1/オッズ）
- 判定: 券種ごとに、レース単位ブートストラップのプール ROI の 95% CI 下限 > 1.0

## 2. fit 窓の α=0 の再校正 β（確定オッズ・1000 回ブートストラップ・seed 42）

| 券種 | R | α=0 の β̂ | 95% CI | EV≥1 の組（点推定の β） | EV≥1 の組（CI 上限の β） |
|---|---|---|---|---|---|
| 馬連 | 3,314 | 1.0700 | [1.0431, 1.0979] | 0 点 / 0R | 1 点 / 1R |
| 3連複 | 3,304 | 1.0912 | [1.0676, 1.1156] | 16 点 / 11R（0.3%） | 83 点 / 47R（1.4%） |

- 除外は 1〜3 着が一意に決まらないレース（同着など）だけ（馬連 16R・3連複 26R）。番兵で落ちた行は 0（確定オッズなので）。
- #722 の dev 窓（2025-07〜12）の値（馬連 1.079・3連複 1.106）より少し小さい。
- ワイドは測っていない。計画レビューで、`benter_alpha` の「組の的中確率 = 3p」の近似が少頭数の本命の組で 1 を超えるなど壊れ、
  EV ≥ 1 で選ばれる組が近似の誤差に支配されることが分かったため（例: 2025-2-niigata-4-6R の 1-3 は 3π = 1.012）。

## 3. 規則が発火するのに要る β（同じ fit 窓・確定オッズ）

| β | 馬連: 本命の組の p/π 中央値 | 馬連: 本命の組の EV 中央値 | 馬連: EV≥1 のレース | 3連複: 本命の組の p/π 中央値 | 3連複: 本命の組の EV 中央値 | 3連複: EV≥1 のレース |
|---|---|---|---|---|---|---|
| 1.07 | 1.099 | 0.849 | 0.0% | 1.132 | 0.848 | 0.0% |
| 1.09 | 1.127 | 0.871 | 0.0% | 1.171 | 0.878 | 0.3% |
| 1.12 | 1.171 | 0.904 | 0.2% | 1.230 | 0.922 | 1.9% |
| 1.15 | 1.214 | 0.938 | 3.3% | 1.290 | 0.968 | 22.2% |
| 1.20 | 1.286 | 0.993 | 44.5% | 1.393 | 1.045 | 76.8% |
| 1.25 | 1.359 | 1.050 | 80.3% | 1.498 | 1.124 | 92.9% |

- 再校正で本命の組が得する分は p/π。EV ≥ 1 には p/π ≥ 1/(1−控除)（馬連 1.29・3連複 1.33）が要る。
- 典型的なレースの本命の組が EV ≥ 1 になるには、β が馬連で約 1.20、3連複で約 1.17 要る。実測の CI 上限（1.098・1.116）は、それより明らかに小さい。
- 本命の組だけを見れば規則が発火するかが分かる: レース内では π × オッズ = 1/Σ(1/オッズ) が一定なので、EV = (p/π) × 定数 は β>1 なら π について単調に増え、
  本命の組で最大になる（fit 窓の全レースで本命の組が EV 最大の組だった）。3連複は無投票の組に下限 π を置く分、定数がわずかに下がる。
- β のモデルのもとで本命の組を毎レース買ったときの期待回収率（本命の組の EV の平均。中央値もほぼ同じ）は、推定値の β で 0.85（馬連）・0.88（3連複）。

## 4. 結論

fit 窓（2025 年・確定オッズ）で、本命の組を毎レース 1 点ずつ買った実績（確定オッズ × 100 = 払戻。レース単位ブートストラップ 2000 回・seed 571）:

| 券種 | R | 的中 | ROI | 95% CI |
|---|---|---|---|---|
| 馬連 | 3,314 | 574 | 0.846 | [0.775, 0.921] |
| 3連複 | 3,304 | 341 | 0.823 | [0.725, 0.921] |

- **(a) 事前に固定した規則（再校正 EV ≥ 1）は、ほとんど発火しないので判定できない。** eval 窓のうちスナップショットがある期間（2026-06-27〜08-31。
  計画レビューで数えた、発走 40 分前の窓に入ったスナップショットがある 3連複のレースは 321R）に、fit 窓の発火率を比例させると、3連複で
  点推定の β なら 1.6 点 / 1.1R（期待的中 0.13 本）、CI 上限の β でも 8.1 点 / 4.6R（同 0.68 本）。馬連はどちらも 0 点。
- **(b) 本命側の組を買う戦略は、β のモデルのもとでも（期待回収率 0.85〜0.88）、fit 窓の実績でも（上の表・CI 上限 < 1）控除を越えない。**
  偏り（β>1）は実在するが、控除（22.5〜25%）より小さい（ADR 0059 の単勝の人気-穴バイアスと同じ形の結論）。
- 参考（判定には使わない）: CI 上限の β で規則が選んだ 3連複 83 点 / 47R を fit 窓で精算すると、的中 10 本・ROI 1.335 [0.567, 2.266]。
  確定オッズで選んで精算した先読みの値で、点数が少なく CI は 1 をまたぐ。点推定の β で選ばれる 16 点は的中 0。
  EV で絞った一部の組が控除を越える可能性は、このデータからは否定できない（それを測れるだけの点数が出ない）。
- 以上から eval 窓は開かず、使わずに残した（qa Q5）。

## 5. 既知の制約

- 推定は確定オッズの市場に対するもの。買う時点（発走 40 分前）の市場の β は測っていない（2025 年にスナップショットが無い）。
  ただし、同じ形の偏りを買う時点で利用するには、β が確定時より 0.1 程度大きい必要があり、そう考える根拠は無い。
- eval 窓での発火数の見積もり（4 節）は、発走 40 分前の市場の本命への集中度と Σ(1/オッズ) が確定時と同じという前提での比例計算。
- モデルは市場確率のべき変換（`p ∝ π^β`）だけ。本命の組の過小評価がオッズ帯によって非線形に効く形は測っていない。
- ワイドは近似が壊れるので測っていない（2 節）。

## 6. 再現

入力（凍結）: `~/paddock-backups/pinned/721-final-odds/final_odds.tsv`（sha256 `83bcef0eeb8e921e4ec31873c5a4ac74fe89fb7a02e2c40a10f34c09f302bd52`）、
`~/paddock-backups/pinned/722-benter-alpha/pl_raw.tsv`（sha256 `8a3a57f3f829d912b1bc701529c1b3b983d8ae652902b308e31e126f96ac5bf9`）。
`scripts/predict-check/benter_alpha.py`（`147496b`）の部品を使う。`fit_beta` は ln π だけを使うので、f はダミー（一様）で `build_race` を通す。
リポジトリのルートで実行する（1000 回で約 1 時間）。

```python
import os, sys
from collections import Counter
import numpy as np
sys.path.insert(0, "scripts/predict-check")
import benter_alpha as ba

PIN = os.path.expanduser("~/paddock-backups/pinned")
LO, HI = "2025-01-01", "2025-12-31"
date, horses, fins = ba.load_results(f"{PIN}/722-benter-alpha/pl_raw.tsv")
prob_odds, payout, dropped = ba.load_odds(f"{PIN}/721-final-odds/final_odds.tsv", wide_low=False)


def races_for(bt):
    out, why = [], Counter()
    for rid in sorted(r for r in date if LO <= date[r] <= HI):
        hs = horses.get(rid, [])
        dummy = {h: 1.0 / len(hs) for h in hs} if hs else {}
        r = ba.build_race(bt, hs, dummy, (1.0, 1.0), fins.get(rid, {}),
                          prob_odds.get((rid, bt), {}), bt == "trio", payout.get((rid, bt), {}))
        (why.update([r.reason]) if r.reason else out.append(r))
    return out, why


def firing(races, beta):  # 再校正 EV >= 1 の (点数, レース数)
    # 売れていない組はオッズが nan なので比較で False になる。正規化 Σπ^β には 3連複の無投票の組（下限 π）も入る（推定と同じ扱い）
    picks = picked = 0
    for r in races:
        pi = np.exp(r.log_pi)
        k = int(np.nansum((pi ** beta / (pi ** beta).sum()) * r.odds >= 1.0))
        picks, picked = picks + k, picked + (k > 0)
    return picks, picked


for bt in ["quinella", "trio"]:
    races, why = races_for(bt)
    beta, _ = ba.fit_beta(ba.pack(races))
    rng = np.random.default_rng(42)
    boots = [ba.fit_beta(ba.pack([races[i] for i in rng.integers(0, len(races), len(races))]))[0] for _ in range(1000)]
    lo, hi = np.percentile(boots, [2.5, 97.5])
    print(bt, len(races), dict(why), round(beta, 4), round(lo, 4), round(hi, 4), firing(races, beta), firing(races, hi))

    # 4 節: 本命の組を毎レース 1 点（払戻 = 確定オッズ）。レース単位ブートストラップ 2000 回・seed 571
    ret = np.array([r.odds[int(np.argmax(r.log_pi))] if int(np.argmax(r.log_pi)) in r.winners else 0.0 for r in races])
    rng = np.random.default_rng(571)
    rois = [ret[rng.integers(0, len(ret), len(ret))].mean() for _ in range(2000)]
    print(bt, "本命の組", int((ret > 0).sum()), round(ret.mean(), 3), np.round(np.percentile(rois, [2.5, 97.5]), 3))
```
