# Step 3.2: サンプルデータ生成

## 目的

データモデルから検証用のサンプルデータ（最小セット）を JSON 形式で生成する。

## 入力

- `docs/catalog/data-model.md`（必須）
- `docs/catalog/app-catalog.md`

## 出力

- `src/data/sample-data.json`

## 実行手順

1. データモデルの主要エンティティを列挙する
2. 各エンティティに最小 1 レコードのサンプルを作成する
3. APP-ID ごとに参照されるエンティティをカバーする
4. JSON 形式で出力する

## 制約

- PII・実データを含めない（架空のサンプルのみ）
- 最小限のレコード数で主要エンティティを網羅する
- 捏造禁止（ただしサンプルデータ自体は架空でよい） / オーバーエンジニアリング禁止
