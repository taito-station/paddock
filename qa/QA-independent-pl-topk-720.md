# QA: 市場非依存の割引 PL top-k（#720・2026-09-27〜29）

#720 の計画承認時に確定した方針の記録。一次資料: `docs-original/720-independent-pl-topk.md`。
蒸留先: `knowledge/learned-model-harness.md`（決定ログ #720）・`knowledge/probability-estimation.md`（独立確率の評価）・`knowledge/ci-pipeline.md`。
前提の方針（独立確率を一級目標にする・券種の優先度・市場とのズレは #722）は `QA-independent-probability-719.md`。

## Q1: 人気・市場の情報が混ざる特徴量をどう扱うか

- 背景: dump の `recent_form`・`jockey_recent_form` は前走人気との差を含む。
- 選択肢: **使わない**（推奨）/ 人気抜きで作り直す / そのまま使う。
- 回答: **使わない**。市場非依存は不変性テスト（市場列を乱しても特徴量が変わらない）と列の許可リストで固定する。

## Q2: 特徴量の元データ

- 選択肢: **`results` のみ**（推奨）/ `horse_past_runs` も使う。
- 回答: **`results` のみ**。`horse_past_runs` は取得済みの馬に偏る（生存バイアス）。

## Q3: 馬のキーと学習期間

- 回答: **馬名**（`results.horse_id` は半数ほどしか埋まっていない）。学習は 2025-03-01 以降（2025-01〜02 は履歴づくりに使う）。
  履歴件数を特徴量に入れる。

## Q4: 同着・中止の扱いと k

- 回答: 着順が一意でない位置の手前で段を打ち切る。中止馬は分母に残す（選ばれる側には入らない）。k は 1〜5 を dev で比べる。

## Q5: 採否基準（事前に固定）

- 回答: dev で Δ馬連 NLL と Δ連対 log-loss が両方 ✅ なら test を 1 回測り、test でも両方 ✅ なら採用。
  比較は同じ実行で並べた pure との対応ありの差。PL は学習 λ と λ=1 の 2 系統を並べる。特徴量 TSV を凍結して sha を記録し、
  p_win は全桁で出す。

## Q6: harness テストの CI

- 背景: CI の注記は harness の学習テストを「棄却済み路線なので対象外（再検討は学習モデル再開時）」としていた。
- 回答（作業中の判断・#719 の「CI に numpy テストを入れる」方針の延長）: 再開したので #720 のテストは CI に載せる。
  scipy までを完全ピンで入れ、scikit-learn が要る旧ハーネスのテストは対象外のまま。

## Q7: issue の当初案からの変更点（作業中の判断・レビュー指摘で記録）

- dump の既存 factor（horse_surface / horse_distance / jockey_* / course_gate ほか）を縮約 m 付きで使う案 → **使わず `results` から作り直した**。
  dump の factor は `horse_past_runs` 由来の集計（Q2 の生存バイアス）と人気由来の成分（Q1）を含み、市場非依存の条件を満たさない。
- 馬 × コース（場 × 芝ダ × 距離帯）の同時条件成績 → **芝ダ・距離・場・馬場の個別適性**にした。学習期間（約 19 か月）では同時条件に当たる走が 1 頭あたり少なすぎ、縮約で全体成績とほぼ同じ値になる。
- 縮約 m・L2 を dev で振る → **今回は固定**（APT_M=2・JOCKEY_M=30・L2=1.0）。dev の反復は k と λ に絞り、比較の回数を抑えた。次の版で dev だけで調整する。
- 組合せ確率を PL から直接出力する → **p_win と λ を出して評価器が再構成**（計画修正コメント C3 で合意済み。割引 PL と割引 Harville は同じモデル）。

## 帰結

- test で事前基準を満たし採用（ledger v2 test）。馬連の擬似 R² 0.057 → 0.179、連対 0.049 → 0.153。
- 市場（単勝オッズ）の参考値（馬連 R² 約 0.265）には届かない。市場と合わせた増分は #722 で判定する。
- 本番の predict・買い目は変えない（#719 の決定 6）。
