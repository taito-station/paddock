# QA: 朝〜直前のオッズでの α 判定（#218・2026-11-03）

#284 の保留（定数は #218 とセットで判断）を解くための測定で、測る前に確定した点と、測定中に改めた点。
回答は 2026-11-03 の会話でユーザーが選んだもの（AskUserQuestion）。
一次資料: `docs-original/218-live-alpha.md`。蒸留先: `knowledge/probability-estimation.md`（決定ログ #218）。

## Q1: 朝オッズで α=0.2 と α=0（市場）の差が言えなかったとき、どちらに倒すか

- 背景: 朝の単勝スナップショットと確定結果がそろうのは 465R・17 開催日で、日クラスタの CI は広く、判定不能になる可能性が高い。
- 回答: **α=0 に倒す**。α=0.2 を残すのは「朝オッズで α=0.2 が市場より有意に良い（model_eval の採用候補）」ときだけ。
  確定オッズでは α=0.2 が有意に悪いと #284 で分かっているので、モデルを混ぜる側に立証責任を置く。

## Q2: どの時点のオッズで判定するか

- 回答: **朝・T-40・直前の 3 時点を測り、朝で判定する**。朝の選定（軸・相手・混戦）が α 入りの確率で組まれて固定されるため、
  影響がいちばん大きい。T-40 と直前は参考。

## Q3（測定中）: 再構成ガード（1%）で止まった件の扱い

- 背景: dump の `model_win` と再構成が一致しないレースが 25/539（4.6%）で、事前に決めた 1% を超えて停止した。α の比較は
  まだ見ていない段階で調べると、23 件は本番が取消馬の implied を市場確率の分母に入れていたことで説明でき（取消馬込みの
  再構成は 1e-16 で一致）、2 件は #284 の既知の型だった。
- 回答: **取消馬で説明できる 23 件は比較に含めて続行**する。ガードは「説明できない不一致が 1% を超えたら停止」に改める。
  各時点の比較は市場・α=0.2 とも出走馬だけで正規化して作るので、dump の当時の正規化に依存しない。
  修正は結果を見る前に issue #218 にコメントした。取消馬の正規化は本番のバグとして #811 で扱う。
